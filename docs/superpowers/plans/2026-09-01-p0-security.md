# P0 Authorization Boundary Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline execution in this task). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Session authorization reflect current user state and scope Trace queries to the caller's permission and Agent identity.

**Architecture:** Keep Session records as server-side opaque identifiers. Resolve the current User on every authenticated request and revoke the current Session on logout. Make Trace query scope an explicit server-side value: console queries require `agent:read`; Agent-key queries include the authenticated `AgentID` in all Trace/Span predicates.

**Tech Stack:** Go, Gin, GORM, MySQL, Redis integration tests, Vitest/Next.js verification.
