# P1-6 Agent 凭证迁移与 HMAC 强制上线实施计划

## 1. 后端数据查询与服务契约

- 在 Agent Repository 增加租户迁移摘要、历史 Agent 分页查询和全局历史凭证计数。
- 所有查询限定 `tenant_id`、活跃 Agent 和活跃凭证，并用 `COUNT(DISTINCT agent_id)` 防止凭证历史造成重复统计。
- 在 Service 层校验分页参数和搜索参数，定义稳定错误码。

## 2. TDD 与 HTTP 接口

- 先添加 Repository/Service/Handler 的失败测试，覆盖租户隔离、摘要分类、分页搜索、无权限和错误映射。
- 实现 `GET /api/v1/agents/migration-status`，挂载 `agent:read` 权限。
- 在 API 启动前增加强制模式预检；查询错误或仍存在历史活跃凭证时拒绝监听。

## 3. 控制台迁移引导

- 增加迁移状态 API 客户端和加载错误状态。
- 在 Agent 管理页面展示剩余历史 Agent、搜索结果及轮换入口，复用已有一次性凭证展示逻辑。
- 明确提示签名强制上线前置条件，不在前端保存或再次展示旧凭证。

## 4. 发布与运维文档

- 增加兼容模式部署、逐 Agent 轮换、SDK 切换、状态复核、强制模式切换、冒烟验证和回退步骤。
